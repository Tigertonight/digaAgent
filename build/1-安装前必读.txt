Diga Agent 安装前必读

当前 Diga Agent 的 DMG 还没有 Apple 开发者签名。
如果你直接把 App 拖进 Applications 后打开，macOS 可能会提示：

  “Diga Agent”已损坏，无法打开

这不是安装包真的损坏，而是 macOS Gatekeeper 对未签名应用加了 quarantine 标记。

推荐安装方式：

1. 打开这个 DMG。
2. 把 “Diga Agent.app” 拖到 Applications。
3. 打开“终端”，先执行第一条命令，移除安装包带来的 quarantine 标记：

  xattr -dr com.apple.quarantine "/Applications/Diga Agent.app"

4. 继续在同一个终端执行第二条命令，清理 App 内部文件的扩展属性，避免本地 agent 运行时报错：

  xattr -cr "/Applications/Diga Agent.app"

5. 再从 Applications 打开 Diga Agent。

如果你已经手动拖入 Applications 但打不开，也按顺序执行这两条命令：

  xattr -dr com.apple.quarantine "/Applications/Diga Agent.app"
  xattr -cr "/Applications/Diga Agent.app"

然后再打开 Diga Agent。
